# 📁 Approovia Frontend Developer Take Home Test

A minimal and interactive project folder management UI built with **React**, featuring **drag-and-drop** reordering, **folder/project selection**, and **inline renaming**.

---

## 🚀 Features

- 🗂 Organize projects into folders
- ✏️ Inline editing of project names
- 🧲 Drag-and-drop project sorting (powered by `@dnd-kit`)
- 💡 Contextual UI states (active selection, dragging overlays)
- 🔥 Toast notifications via `react-hot-toast`

---

## 📦 Tech Stack

- **React**
- **TailwindCSS**
- **@dnd-kit/core**
- **react-hot-toast**
